📲 Pasang Aplikasi di HP (PWA)

SIDA-JAMAAH DESA

Pasang aplikasi di layar utama HP Anda agar bisa dibuka cepat satu ketukan tanpa repot mengetik link lagi.

🤖 Untuk HP Android (Google Chrome)
  1. Buka link aplikasi ini di browser Google Chrome HP Anda.
  2. Ketuk ikon titik tiga (⋮) di pojok kanan atas browser.
  3. Pilih menu "Instal aplikasi" atau "Tambahkan ke Layar Utama" (Add to Home screen).
  4. Ketuk Instal / Tambah. Ikon aplikasi langsung muncul di layar HP Anda!
🍎 Untuk iPhone / iPad (Safari)
  1. Buka link aplikasi ini di browser Safari.
  2. Ketuk tombol Bagikan (ikon kotak dengan tanda panah ke atas di bilah bawah).
  3. Gulir ke bawah, lalu pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
  4. Ketuk Tambah di pojok kanan atas.
